# 2017 Ford Transit T-250 — Listing

Static listing page. Plain HTML and CSS: no build step, no JavaScript, no
dependencies. Open `index.html` in a browser, or serve the folder as-is.

- `index.html` — the page
- `styles.css` — all styling (linked with a `?v=N` query; bump it when you edit
  the CSS so browsers don't serve a stale copy)
- `images/` — photos, all EXIF-stripped

Published with GitHub Pages from the repository root.
